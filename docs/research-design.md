# NAAS v0 研究设计

## 研究切入点

从机器人主动感知和面向任务的采样调度借一个成熟思想：只为后续决策可能改变的信息付费。迁移到生活助理后，决策对象变成跨天的**未完成承诺**，观测变成对具体服务和实体的读操作，错误表现为在过期证据上维持计划、错过修订窗口，或过早打扰用户。例子是已持有的航班方案可能受时刻变化影响。接近登记截止时，核对已有预订的状态可能比搜索更多备选航班更有价值。这个例子用于说明机制，尚未当作已观测到的模型失败。

主假设 H1 是在同样的读预算与观察机会下，依据承诺的决策后果调度复查，比按时间间隔、状态变化概率或信息增益选择来源更早发现会改变计划的变化。H2 是在证据可靠性或可用时间变化时，应有可预测的策略分歧，包括直接维持计划、改查另一来源和在时限内保持沉默。用户打扰偏好只是后续可检验的子因素，基准原设置中的长期计划与静默变化是主线。

## Training-free 策略

1. 从已经观察到的用户请求、计划和工具结果提取活动承诺。每条保存当前方案、相关实体、允许的只读来源、上次核验时刻、可观察的截止时间，以及哪种结果会触发哪个局部修订。模型只提议这些结构化字段。字段能否从输入追溯由独立验证器检查。
2. 在共同的决策时刻构造 `(service, entity, read)` 候选。候选必须能在剩余时间内完成，且入口的权限符合任务设置。固定的短表给出来源可靠性和按时间变化的风险区间，表格来自公开服务语义、可见的过期条件及开发集检查。初版冻结表格、提示和模型权重。读失败或口径冲突时更新可用证据，保留不确定性。
3. 对每个候选估计一个局部决策价值。设 `D(b)` 为现有证据下当前可行决定的最高期望效用，候选读取 `q` 的打分为 `E_y[D(b | q, y; t+latency)] − D(b; t) − cost(q)`。期望只覆盖可读且有直接分歧的几类结果，例如无变化、已改变、未知。保持计划、修订草稿、通知用户各有不同效用。估计模型暂不稳时，比较多个预设风险值下的分数，报告中央估计和保守区间两个版本。规则分数是工程近似，精确贝叶斯模拟只提供小规模参照。
4. 选择最高的正值只读动作，更新相关承诺。预算用完、已无正值或截止已到时结束该轮。继续监控使用已有可见时钟与下一次预定检查时刻。观察成功后仍需单独作出是否通知或请求确认的决策。

主方法采用单步比较。两步前瞻在小模型里提供上界或诊断，当工具读数模型失配时应记录其退化。模拟中一条候选证据如果只改变同一个最优决定的置信度，在固定时间与正确概率模型下，其期望决策收益为零。这是线性期望和全期望公式的直接结果，不能据此对模型预测误差作现实保证。

## 最接近的工作

| [VibeLifeBench](https://arxiv.org/html/2608.10875) | 有虚拟时钟、静默状态变化、长期工作区与分阶段验收 | 先查清已发布运行器何时真正给模型一轮。寻找因读取时机或来源造成的可复现错误 |
| [ProAgent §4.4](https://arxiv.org/html/2512.06721#S4.SS4) | 用低成本传感线索启动视觉采样，推断出的主动需求继续控制采样频率 | 同预算的低成本事件＋需求触发。比较近截止的具体承诺能否带来额外收益 |

| [ProAct](https://arxiv.org/html/2605.25971v1) | 预测需求，并按相关性、知识缺口、增量价值和时效分配空闲时间去取证 | 比较基于目标与知识缺口的通用提示式采集。论文须说明被验证的差异落在已知承诺和未通知的状态变化 |
| [PRISM](https://proceedings.iclr.cc/paper_files/paper/2026/file/ba1293b663ddd4a29c6854e4d3bf766a-Paper-Conference.pdf) | 以风险敏感阈值决定介入，靠近阈值时增加推理 | 加入决策边界附近才读的基线，同时固定推理预算，区分想得更多与看到新证据 |
| [Need graph 与 Q&D](https://arxiv.org/html/2609.37236) | 衡量工具型助手主动追问哪些隐含证据及何时停止 | 检查多个读数有前置依赖的案例，单独报告这类失败 |

## 论文成立的条件

先做 VibeLifeBench 的失败归因。固定同样的模型和后续修订器，证明把决定性的工具结果在原时间窗补给模型，执行质量能恢复。再在独立任务族上验证，采集策略能用同等资源自主发现这些结果。主比较必须包含最强的固定间隔、到期前重查、允许选证据的提示式策略及来源优先级消融。严格区分观测受限和观测后仍误判，避免把所有长程失败归给感知。

若诊断样本中没有稳定的可恢复观测失败，或按截止时间重查已解释全部收益，算法主张应收窄。贵的计算、额外唤醒次数和更强的执行器都应纳入对照。可用论文标题是 *Which Evidence Is Worth Refreshing? Cost-Aware Active Sensing for Long-Horizon Personal Agents*。

## 网页讨论的第一轮待核对问题

1. 原案对「需求」和「观察动作」的最小定义是什么？候选排序依据侧重证据新鲜度、拥塞下的监控优先级，还是当前要执行的下一步？
2. 原案能否指出两个典型失败，并具体到任务、可观察窗口、候选读操作和受影响的评分项？哪些例子已有明显同主题通知？
3. 如果固定时间预查加一个到期规则就够用，剩下最小可测试难点在哪里？需要证明决策价值优于哪条已有强基线？
4. A+B 中 A 的可复现失败是什么，B 的哪个具体部件能修复它，哪些结果会推翻这个假设？先比较可证伪性，再决定叙事。
